# Clerk exports

Drop CSV files exported from the County Clerk portal here
(hidalgo.tx.publicsearch.us → run a search → **Export all Results**).
Uploading one through GitHub's web page starts a Distress Watch refresh.

The "New filings" tab on the Distress dashboard has one-click links to the
searches worth exporting (heirship, wills/probate, lis pendens, liens,
judgments, trustee appointments, foreclosure notices) for the last 7 days.
